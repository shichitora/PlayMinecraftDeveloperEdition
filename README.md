# Minecraft Developer Editionの遊び方

## Windows

1. [ここ](https://github.com/shichitora/PlayMinecraftDeveloperEdition/releases/tag/developer)からZIPファイルをダウンロードする
2. ファイルをすべて解凍する
3. PowerShellのコマンドプロンプトを開く
4. `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process`を実行する
5. `cd`コマンドで解凍したフォルダに移動する
7. そのフォルダの`Install.ps1`のパスを貼り付けで実行する
   - もし依存パッケージに関するエラーが出た場合それをGoogleなどで調べ安全なものをインストールしてください
8. Minecraftを開く（ロードが止まる場合は何回も再起動すればなおります）

## Android

1. [ここ](https://github.com/shichitora/PlayMinecraftDeveloperEdition/releases/tag/developer)からAPKファイルをダウンロードする
2. そのファイルをインストールする
